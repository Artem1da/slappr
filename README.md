# Slappr 👋

Приложение для MacBook, которое воспроизводит случайный звук из коллекции, когда вы шлёпаете по ноутбуку.

## Требования

- **macOS 13.0** (Ventura) или новее
- **Apple Silicon** (M1/M2/M3/M4) — используется встроенный MEMS акселерометр
- **Xcode 15+** для сборки

## Как собрать

1. Откройте `Slappr/Slappr.xcodeproj` в Xcode
2. Выберите целевое устройство: **My Mac**
3. Нажмите **Cmd+R** для сборки и запуска

Или через терминал:

```bash
cd Slappr
xcodebuild -scheme Slappr -configuration Release build
```

## Как добавить звуки

1. Положите аудио файлы (`.mp3`, `.wav`, `.aiff`, `.m4a`) в папку `Slappr/Slappr/Sounds/`
2. В Xcode убедитесь, что файлы добавлены в проект (перетащите в навигатор проекта)
3. Пересоберите приложение

Если звуки не добавлены, при шлепке будет воспроизводиться системный звуковой сигнал.

## Как работает

- Приложение живёт в **строке меню** (без иконки в Dock)
- Использует **IOKit HID** для чтения данных акселерометра Apple Silicon
- Определяет резкие удары по порогу ускорения (настраиваемый)
- Воспроизводит **случайный звук** из коллекции при каждом шлепке
- Cooldown 0.5с между срабатываниями для предотвращения повторов

## Интерфейс

В меню приложения доступно:
- **Включить/выключить** детекцию шлепков
- **Ползунок чувствительности** — настройка порога срабатывания (0.5g — 4.0g)
- **Тест звука** — проверить воспроизведение без шлепка
- Отображение текущего ускорения в реальном времени

## Важно

При первом запуске macOS может запросить разрешение на доступ к устройствам ввода (Input Monitoring). Это необходимо для чтения акселерометра через IOKit HID.

Если приложение не работает без sandbox, убедитесь что `App Sandbox` выключен в `Slappr.entitlements`.
